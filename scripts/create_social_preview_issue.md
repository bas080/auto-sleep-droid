# Issue: Update Repository Social Preview Image on GitHub

## Description
A square repository social preview image matching the app launcher icon design (`ic_launcher`) has been created and stored at `assets/social-preview.png`.

Since updating the repository's social preview image on GitHub requires administrative access to repository settings on GitHub.com, this issue tracks updating the setting manually.

## Steps to Apply Social Preview Image
1. Go to repository settings on GitHub: [https://github.com/bas080/auto-sleep-droid/settings](https://github.com/bas080/auto-sleep-droid/settings).
2. Scroll to the **Social preview** section under the **General** settings tab.
3. Click **Edit** -> **Upload an image...**.
4. Select `assets/social-preview.png` from the repository assets folder.
5. Save changes.
